# Product Capabilities

This directory records both available product behavior and proposed customer
capabilities. A checked item is implemented and covered by automated tests. An
unchecked item is a product requirement, not an implementation claim.

## Available

- `01-platform-contracts-and-printing.md`: supported printers, Bluetooth
  connection, image preparation, printing, and printer information.

## Proposed

- `02-app-quick-printing.md`: a focused Android and Linux workflow for entering
  text and printing it directly to a nearby printer, with Apple platforms kept
  as a future extension.
- `03-label-layout-and-preview.md`: deterministic physical layout, typography,
  orientation, fitting, validation, and preview.
- `04-templates-and-icons.md`: reusable label templates and a curated local icon
  catalog.
- `05-ai-assisted-composition.md`: optional natural-language composition that
  produces a validated label draft without controlling the printer directly.
